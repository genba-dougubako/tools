# 車種・機体の候補とリサーチメモ

## 調査の限界(先に)
- 使った検索は Reddit / YouTube / X の投稿本文を拾えません。「ネットの声」としては、フォーラムの一部の投稿と、攻略メディアの主観ランキングしか取れていません。
- 以下の「Roblox 内の人気」は **傾向の手がかり** であり、集計された人気順位ではありません。
- 本当の声を集めるなら、(1) 各ゲームの公式ページのコメント欄、(2) Reddit の r/roblox などを人が直接検索、(3) 人気ゲームの Discord、の方が確実です。集めた生の声を貼ってもらえれば、整理・集計します。

分かったこと:
- **Car Crushers 2 は 400 台超の車を、実在車のパロディ名(例: Nyssat T80 GTR = 実在の GT-R50 のもじり)で出している。** 権利リスクを避ける実例として参考になる。
- **Driving Empire は 300 台超で、実在ブランドをライセンスで入れている**(公式ページに「提携・推奨ではない」旨の免責あり)。
- 両ゲームとも「高額で速い車」「限定・特別枠の車」が話題になりやすい。
- 他に、運転系で名前の出たゲーム: Greenville、Southwest Florida、Mojave Valley、Midnight Racing: Tokyo、Vehicle Legends(いずれも編集記事のリスト。人気順位ではない)。

## 国産/海外の車リスト(実装済み・仮名)
実装済みの名前と参考車の対応は `src/shared/VehicleCatalog.luau` の `Inspiration` を参照。
候補は「仮決め」として全部入れてある。消去法で絞るときは、カタログから行を消すだけで外せる。
