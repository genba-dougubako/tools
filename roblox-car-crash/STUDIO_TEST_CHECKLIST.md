# Studio 検証チェックリスト(プレス機)

Studio MCP でプレイテストするときの確認項目です。すべて **未確認** の状態から始まります。
結果は `[x]` / `[ ]` と、失敗時は Output のエラーを添えて記録してください。

## 事前
- [ ] 既存プロジェクトのバックアップを取った(`File > Save to File As...` で .rbxl を別名保存)
- [ ] Racing テンプレートの既存スクリプト/車と名前衝突がない(`Cars`, `Map`, `CarPress`, `Remotes`)
- [ ] 本リポジトリの `src/` を Rojo で同期、または各ファイルを同名の Script/ModuleScript/LocalScript として配置

## 基本動作(1人)
- [ ] 起動時に Output にエラーが出ない
- [ ] GARAGE → SPAWN で車が出て、W/S/A/D で運転できる(逆なら `Config.DriveSign` / `SteerSign`)
- [ ] 画面上部に `$` と `COINS 0` が表示される
- [ ] スポーン地点の東(+X 約 70 studs)に大型プレス機がある
- [ ] 車をプレス内に入れ、操作盤の赤ボタンに近づくと `Start Press` が出る

## プレス機
- [ ] プレス外に車がある状態で押す → `Park your car inside the press` が出て作動しない
- [ ] 車を入れて押す → 運転手が操作盤の手前へ移動し、警告灯が点滅
- [ ] 板が落ち、車が潰れ、火花・煙・カメラ揺れが出る
- [ ] `COINS` が 100 増え、`CRUSHED! +100 COINS` が出る
- [ ] 板が上がっても車は潰れたまま
- [ ] 板が上がり切った後、車が消え、入口外に同じ車が再出現して運転席に座れる
- [ ] 2回目以降も同様に繰り返せる(100 → 200 → ...)

## 検証・不正対策
- [ ] 作動中に別プレイヤーが押す → `Press is busy`
- [ ] 作動中に Reset(R)/GARAGE から車を出しても、コインが二重に入らない
- [ ] 車を出さずに押す → `Spawn a car first`
- [ ] 操作盤から 20 studs 以上離れた状態では作動しない(ProximityPrompt の距離外)
- [ ] 他プレイヤーがプレス内にいると `Clear the press area`
- [ ] 作動中にプレイヤーが退出してもエラー・ハングがない(以降もプレスが使える)

## マルチプレイ(Studio の Test > Clients and Servers)
- [ ] 2〜3人で同時に入室でき、各自の車・コインが独立している
- [ ] 他プレイヤーの車を潰せない(操作者本人の車のみ対象)

## 既知の制約
- 効果音なし(有料/外部素材を使わない方針のため)
- コインは保存されない(初日の対象外)。現金 `$`(衝突で稼ぐ)とは別カウンター
- 潰れ表現はパーツの縦方向スケールによる簡易アニメ。傾いた車は入場不可(水平のみ)
