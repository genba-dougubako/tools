# Studio 検証チェックリスト(プレス機)

Studio MCP でプレイテストするときの確認項目です。すべて **未確認** の状態から始まります。
結果は `[x]` / `[ ]` と、失敗時は Output のエラーを添えて記録してください。

## 事前
- [ ] 既存プロジェクトのバックアップを取った(`File > Save to File As...` で .rbxl を別名保存)
- [ ] Racing テンプレートの既存スクリプト/車と名前衝突がない(`Cars`, `Map`, `CarPress`, `Remotes`)
- [ ] 本リポジトリの `src/` を Rojo で同期、または各ファイルを同名の Script/ModuleScript/LocalScript として配置

## 基本動作(1人)
- [ ] 起動時に Output にエラーが出ない
- [ ] GARAGE → SPAWN で車が出て、W/S/A/D で運転できる(逆なら `Config.DriveSign` / `SteerSign`)
- [ ] 画面上部に `$` と `COINS 0` が表示される
- [ ] スポーン地点の東(+X 約 70 studs)に大型プレス機がある
- [ ] 車をプレス内に入れ、操作盤の赤ボタンに近づくと `Start Press` が出る

## プレス機
- [ ] プレス外に車がある状態で押す → `Park your car inside the press` が出て作動しない
- [ ] 車を入れて押す → 運転手が操作盤の手前へ移動し、警告灯が点滅
- [ ] 板が落ち、車が潰れ、火花・煙・カメラ揺れが出る
- [ ] `COINS` が 100 増え、`CRUSHED! +100 COINS` が出る
- [ ] 板が上がっても車は潰れたまま
- [ ] 板が上がり切った後、車が消え、入口外に同じ車が再出現して運転席に座れる
- [ ] 2回目以降も同様に繰り返せる(100 → 200 → ...)

## 検証・不正対策
- [ ] 作動中に別プレイヤーが押す → `Press is busy`
- [ ] 作動中に Reset(R)/GARAGE から車を出しても、コインが二重に入らない
- [ ] 車を出さずに押す → `Spawn a car first`
- [ ] 操作盤から 20 studs 以上離れた状態では作動しない(ProximityPrompt の距離外)
- [ ] 他プレイヤーがプレス内にいると `Clear the press area`
- [ ] 作動中にプレイヤーが退出してもエラー・ハングがない(以降もプレスが使える)

## マルチプレイ(Studio の Test > Clients and Servers)
- [ ] 2〜3人で同時に入室でき、各自の車・コインが独立している
- [ ] 他プレイヤーの車を潰せない(操作者本人の車のみ対象)

## 既知の制約
- 効果音なし(有料/外部素材を使わない方針のため)
- コインは保存されない(初日の対象外)。現金 `$`(衝突で稼ぐ)とは別カウンター
- 潰れ表現はパーツの縦方向スケールによる簡易アニメ。傾いた車は入場不可(水平のみ)

## 飛行機・ヘリ・リング・イベント(追加分・すべて未確認)
- [ ] GARAGE に 54 台が並び、ALL / JP / IMPORT / AIR のタブで絞り込める
- [ ] 車の形が種類で変わる(軽・ミニバンは箱型、ピックアップは荷台、スポーツはウイング)
- [ ] Sky Trainer をスポーン → 道路を `E` で加速 → 離陸速度で `S` を押すと機首が上がり離陸できる
- [ ] 速度が足りないと失速して機首が落ちる(飛び続けるには加速が必要)
- [ ] `A/D` で旋回、機体が傾く。降りると機体が落下する
- [ ] 高度が HUD に出る(`ALT ... m`)
- [ ] Rescue Copter が `E` で上昇、押さなければホバリング、`W` で前進
- [ ] 空に 10 個のリング(番号つき)がある。1 → 2 → ... の順に通るとコイン加算と通知
- [ ] 連続で通るとコンボで報酬が増える。15 秒空けるとやり直しの通知
- [ ] 全部通ると +100 の完走ボーナス、EVENTS の「Sky Ring Challenge」が CLEARED になる
- [ ] クリア後、Sky Jet が `BUY` に変わる。クリア前に買おうとすると `Locked:` が出る(サーバー側で拒否)
- [ ] 車を 5 台プレス(国産系 2+、海外系 2+)で「Scrap Quota」クリア → Heavy Truck が買える
- [ ] 飛行機はプレスに入らない(`Only cars fit in the press`)
- [ ] 飛行機で地面・壁に突っ込むと体力が減り、0 で爆発して操縦不能になる
- [ ] 調整: 離陸が難しい/簡単すぎる → 車種ごとの `TakeoffSpeed` `StallSpeed` `Accel`

## 追加機体・吊り下げ・対決戦(すべて未確認)
- [ ] 10 機すべてスポーンでき、形が崩れない(複葉の上翼、フロート、旅客機のエンジン、タンデムローター、ティルトローター)
- [ ] プロペラ・ローターが回り、降りると止まる
- [ ] Air Liner は大きく重く、旋回が遅い。Strike Fighter は最速
- [ ] Bush Hopper はフロートで地面に置ける(沈まない・跳ねない)
- [ ] Sky Crane で車の真上から `F` → ロープで吊れる。もう一度 `F` で離す。運転中の車は吊れない
- [ ] 3 台吊ると「Heavy Lift」クリア → Gunship / Tilt Rotor が買える
- [ ] 起動 1 分後に「SHOWDOWN START」、画面上部に残り時間とスコア
- [ ] ラウンド中にプレスすると、その車のデザインの側に点が入る。終了時に勝敗の通知
- [ ] 勝った側でプレスした人だけ「Domestic vs Import Showdown」クリア → スーパーカーと Strike Fighter が買える
- [ ] テスト時は `Config.ShowdownFirstDelay` / `ShowdownDuration` を短くすると早く確認できる
